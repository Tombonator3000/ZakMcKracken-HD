# ZakMcKracken-HD: spilldata

Spillfilene til *Zak McKracken and the Alien Mindbenders*, engelsk FM-Towns-utgave (00.LFL MD5 `2d4536a56e01da4b02eb021e7770afa2`, 7 520 byte). Grenen har ingen felles historikk med `main`.

Hent dem med `tools/hent_spilldata.sh` fra `main`. Skriptet legger filene i `game/` og sjekker `game/SHA256SUMS`.

- `00.LFL` er indeksen, `01.LFL` til `59.LFL` er rommene med skript, kostymer og lyder, `98.LFL` og `99.LFL` er de to tegnsettene.
- `Track1.fla` til `Track21.fla` er CD-musikken (FLAC). ScummVM spiller dem i stedet for CD-sporene når motoren er bygget med FLAC.

Spillet tilhører Disney/Lucasfilm. Filene brukes bare til HD-arbeidet i dette repoet.
