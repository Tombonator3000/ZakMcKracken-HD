# Malte ikoner til verbhjulet

15 tegnede ikoner fra leveransen 15. oktober 2026, lagt inn etter Toms direkte bestilling. PNG med ekte alfa, 512 x 512. Filnavnene følger motorens verbnavn. `zakhd build-mod` tar dem automatisk med som `ui/verbhjul/<navn>.png`; manglende ikoner bruker fortsatt de innebygde.

[Galleri og produksjonsnotat](../../rapporter/hjul-inventar-20261015/notat.md), med prompter, kilder, varianter og usikkerhet. Filene er kontrollert med `build_ui`; denne leveransen er ikke prøvd i spillmotoren. Eksisterende innebygde ikoner i `../verbhjul/` beholdes.

11 håndikoner er rettet etter Toms retur: fem fingre, bare hender uten klær og fedora i begge hattikonene. [Før/etter og nye prompter](../../rapporter/verbhjul-hender-20261015/README.md). Rettelsen er til kontroll og ikke prøvd i motoren.
