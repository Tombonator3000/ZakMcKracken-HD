# Malte ikoner til verbhjulet

Godkjente ikoner fra ChatGPT legges her, med samme filnavn som de innebygde i [../verbhjul/](../verbhjul/) (`pick-up.png`, `use.png` og så videre). PNG med alfa, kvadratiske, gjerne 512 x 512. `zakhd build-mod` legger dem i modden under `ui/verbhjul/`, og motoren bruker dem i stedet for de innebygde. Et ikon som ikke ligger her, vises som det innebygde.

Tom: ingen er bestilt eller godkjent ennå (15. oktober 2026). Bestillingen står i `docs/BESTILLING-CHATGPT.md`.
